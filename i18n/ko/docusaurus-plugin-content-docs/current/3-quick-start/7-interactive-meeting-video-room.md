# Interactive Meeting 비디오룸

`Interactive Meeting` 유형의 비디오룸은 사용자의 의도에 따라 여러가지 목적으로 사용될 수 있지만 온라인을 통한 교육을 위한 도구로 사용되는 것을 목표로 설계 되었습니다. 비디오룸의 전반적인 제어를 소수의 참여자들에게만 주어지고 그들의 주도에 따라 다른 참여자들이 여러가지 활동을 할 수 있도록 개발 되었습니다. 이 문서에서는 `Interactive Meeting` 유형의 비디오룸에서 제공하는 기능을 소개하고 사용법을 설명합니다.

## 비디오룸의 속성

`Interactive Meeting` 유형의 비디오룸은 다음의 속성을 가지고 있습니다.

- title (제목)
- description (설명)
- access level (접근 범위)

그리고 다음의 설정이 가능합니다.

- auto record
- allow global chat
